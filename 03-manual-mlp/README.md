# 03 Manual MLP

Focus: build a tiny neural network with raw tensors before using `torch.nn`.

## Exercises

- Generate a small 2D classification dataset.
- Initialize weight matrices and biases manually.
- Write the forward pass with matrix multiplication and activation functions.
- Compute cross entropy or a simple classification loss.
- Backpropagate with autograd.
- Update weights manually.
- Track train accuracy.

## Debugging Checklist

- Do tensor shapes match?
- Is loss decreasing?
- Are gradients non-zero?
- Can the model overfit a tiny dataset?
