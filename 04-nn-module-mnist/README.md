# 04 `nn.Module` MNIST

Focus: learn the normal PyTorch training workflow.

## Exercises

- Load MNIST or Fashion-MNIST with `torchvision`.
- Use `Dataset` and `DataLoader`.
- Define a model with `nn.Module`.
- Use `nn.Linear`, activation functions, and `nn.CrossEntropyLoss`.
- Use `torch.optim.Adam` or SGD.
- Write train and eval loops.
- Save and load model weights.
- Try CPU vs MPS if available.

## Concepts

- `model.train()` vs `model.eval()`
- batches and dataloaders
- optimizer lifecycle
- checkpointing
- device placement
