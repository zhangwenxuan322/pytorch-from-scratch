# 02 Autograd Linear Regression

Focus: understand autograd by fitting `y = 3x + 2` with gradient descent.

## Exercises

- Generate synthetic data.
- Initialize `w` and `b` manually with `requires_grad=True`.
- Compute predictions with tensor operations.
- Compute mean squared error.
- Call `.backward()`.
- Update parameters inside `torch.no_grad()`.
- Clear gradients after each step.
- Plot or print loss over time.

## Concepts

- `requires_grad`
- `.backward()`
- `.grad`
- `torch.no_grad()`
- `.detach()`
- computation graph lifecycle
