# 01 Tensors

Focus: tensor creation, shapes, indexing, broadcasting, matrix multiplication, dtype, device, and reshape operations.

## Exercises

- Create tensors from Python lists.
- Create random, zeros, ones, and range tensors.
- Inspect `.shape`, `.dtype`, and `.device`.
- Practice indexing and slicing.
- Practice broadcasting with different shapes.
- Use matrix multiplication with `@` and `torch.matmul`.
- Compare `view`, `reshape`, `transpose`, `permute`, `unsqueeze`, and `squeeze`.
- Move tensors to `mps` if available on Mac.
